# Icons

App icons should be placed in the respective mipmap directories:
- mipmap-mdpi: 48x48
- mipmap-hdpi: 72x72
- mipmap-xhdpi: 96x96
- mipmap-xxhdpi: 144x144
- mipmap-xxxhdpi: 192x192

Icon files should be named:
- ic_launcher.png (square icon)
- ic_launcher_round.png (round icon)

For now, the app will use default React Native icons.
